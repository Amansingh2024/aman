# Sen Diagnostics - Premier Pathology Laboratory & Diagnostic Center

> NABL Accredited | Established 1965 | Patna, Bihar | Project by Aman

A modern, responsive, high-performance web platform for **Sen Diagnostics**, featuring 3D health package flip cards with complete diagnostic parameter breakdowns, intelligent test searching, mobile sticky quick-action bar, and seamless booking actions.

---

## 🌟 Key Features

- **Cross-Platform Responsive Design:** Flawless rendering across iPhone (iOS Safari), Android smartphones, and Laptops/Desktops.
- **3D Flip-Flop Diagnostic Cards:** Tactile touch and hover flip cards showcasing full authentic clinical parameters (CBC, LFT, KFT, Lipid Profile, Cardiac Markers, Diabetes Monitoring, etc.).
- **Mobile Sticky Quick-Action Bar:** Frosted glassmorphism bar with iOS safe-area inset support, instant Home Visit booking, Call Direct, and Packages navigation.
- **Live Search & Filter:** Instant search and category filtering for tests and diagnostic packages.
- **Direct WhatsApp & Phone Integration:** One-tap booking and inquiry directly linked to Sen Diagnostics clinic contact lines.
- **GitHub Pages Ready:** Configured with relative asset resolution and `.nojekyll` for immediate static hosting.

---

## 🚀 Live Demo & Pages
